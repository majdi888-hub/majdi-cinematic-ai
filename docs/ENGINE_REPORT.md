## المنفذ والمختبر فعليًا (بشفرة التطبيق، على الحاسوب وفي GitHub Actions)
- Cinematic Fusion Pro (افتراضي 65%) بمسار موحد من 6 مراحل وموازنة نهائية، و4 قوى مستقلة.
- 5 إعدادات سينمائية بـ LUT ومنحنيات مختلفة؛ Dramatic؛ Natural Pro؛ DSLR بمحاكاة 35/50/85mm وf/1.8–5.6.
- أداة تمويه: لمس جسم كامل أو مستوى، مدى التركيز، حدود الجسم، إظهار المنطقة الحادة.
- AI Auto: قواعد حسابية على مخرجات نموذجي العمق والعزل وإحصاءات مقاسة (ليس نموذج تعلم آلي للقرار).
- تقليل ضوضاء حافظ للحواف بتداخل أشرطة 3 صفوف؛ توازن أبيض وحرارة لونية.
- الصورة المرجعية بدقتها الأصلية 1659×2212: الملمس ×1.11–×1.35 في Dramatic، لا هالات حول المروحة، المعاينة تطابق الحفظ (0.3–1.8/255).
- الوجوه: الملمس ×0.97–×1.03، لا تغميق، انحراف البشرة < 1.6°.
- CI: تطابق الأشرطة 0 بكسل في كل الأنماط (منها صورة بضوضاء 4.2 لاختبار التنظيف)، اختبار أداة التمويه، العمق عبر Java يطابق Python (0.9999).

## منفذ ولم يُختبر على هاتف حقيقي
- الواجهة كلها (الأزرار الستة، الإعدادات المتقدمة، اللمس، التكبير، شريط التقدم، الحفظ بصيغ JPEG/PNG/WEBP).
- الأزمنة واستهلاك الذاكرة على S25 Ultra، والتثبيت على Android 16/17.
